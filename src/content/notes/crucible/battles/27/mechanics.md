**Administrator Piece** — possible triple-card fight.

**Suggested trio:** [Adamantoise](../../../bestiary/adamantoise/), [Spriggan](../../../bestiary/spriggan/), [Geshunpest](../../../bestiary/geshunpest/) — tankiness, an interrupt and Lightning damage.

## Abilities

- **Flamethrower** — frontal cone
- **Confound** — interruptible Confusion

### Adds

- **Bug** — walks to the orb; if it arrives the boss casts Object 199 (damage + regen)
- **Drone** — baited lines
- **Footman** — follows you, periodic circle
- **Cobra** — Noxious Nova — cleansable poison, but each cast is a separate stack
- **Dreadnaught** — frontal cone

## How to handle it

Borrow Soul Crush from Spriggan, interrupt Confound, kill the Bug first. It dies so fast that Mantis / Damselfly / Wespe can end it before anything happens.
